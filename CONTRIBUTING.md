# Contributing to Grafana Metrics Drilldown

Thank you for your interest in contributing to Metrics Drilldown. Contributions are welcome for bug fixes, documentation, tests, accessibility improvements, and focused features.

Please read the complete [contribution guide](docs/contributing.md) before opening a pull request. It covers the development setup, repository workflow, testing expectations, documentation and i18n requirements, and pull-request checklist.

## Quick start

```sh
pnpm install --frozen-lockfile --ignore-scripts
pnpm dev
pnpm lint
pnpm typecheck
pnpm test:ci
```

Node.js 22 and Docker or OrbStack are required for the full development workflow. See the contribution guide for local development and documentation preview commands.

## AI-assisted contributions

AI tools may assist with contributions when the result is actively reviewed and understood by the human contributor. Read the [Generative AI Contribution Policy](docs/genai.md), disclose substantial AI assistance in the pull-request template, and do not submit unreviewed or automatically generated changes.
